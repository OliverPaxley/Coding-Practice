# C++ Workshop 3: Multiple Mark Evaluation

## Objective

Create a C++ console application in **Visual Studio** that receives multiple numeric marks, determines the **letter grade** for each mark, displays whether each mark is a **pass** or a **fail**, and prints a final report.

## Instructions

Create a new **Console App** project in **Visual Studio**.

Write a program that does the following:

* asks the user how many marks will be entered
* receives that number of marks from the user
* before each mark is entered, displays a prompt showing the **row number**
* determines the corresponding **character grade** for each mark
* determines whether each mark is a **pass** or a **fail**
* displays the result for each entered mark
* after all marks are entered, displays:

  * the **average** of all marks
  * the **total number of passes**
  * the **total number of failures**

## Grade Rule

Use the following grading scale:

* `A` for marks from **80 to 100**
* `B` for marks from **70 to 79**
* `C` for marks from **60 to 69**
* `D` for marks from **50 to 59**
* `F` for marks below **50**

A mark of **50 or above** is considered **Pass**.
A mark below **50** is considered **Fail**.

## Requirements

* Use `cout` to display prompts and results.
* Use `cin` to receive input.
* First receive the **number of marks**.
* Then use repetition to receive and process each mark.
* Each prompt must show the row number, such as:

  * `Mark 1:`
  * `Mark 2:`
  * `Mark 3:`
* For each mark, display:

  * the entered mark
  * the character grade
  * whether it is pass or fail
* At the end of the program, display:

  * the average of all entered marks
  * the total number of passing marks
  * the total number of failing marks

# Workshop: Processing Multiple Student Marks

In this workshop, write a program that asks the user how many marks will be entered. Then, one by one, the program must prompt for each mark using its row number, determine its letter grade, and indicate whether it is a pass or fail. After all marks are processed, the program must print a summary showing the average of all marks, the total number of passes, and the total number of failures.
