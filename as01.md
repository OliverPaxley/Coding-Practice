
# C++ Assignment 1: Adding Two Numbers

## Objective

Create a C++ console application in **Visual Studio** that receives **two numbers** from the keyboard and displays their **sum**.

## Instructions

* Create a new **Console App** project in **Visual Studio**.
* Name the project appropriately.
* Write a program that:

  * asks the user to enter the first number
  * asks the user to enter the second number
  * calculates the sum of the two numbers
  * displays the result on the screen

## Requirements

* Use `cout` to display prompts and the result.
* Use `cin` to receive input from the user.
* Store the numbers in variables.
* The output must clearly show the sum.

## Example Execution

```text
Please enter the first number: 12
Please enter the second number: 8
The sum is: 20
```

## Submission Requirements

* Submit the **Visual Studio project**.
* Make sure the program compiles and runs correctly.

## Marking Criteria

* Project created correctly in Visual Studio
* Proper input of two numbers
* Correct calculation of the sum
* Clear and correct output
* Good coding style and readability
