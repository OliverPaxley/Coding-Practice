# C++ Assignment 2: Mark Evaluation

## Objective

Create a C++ console application in **Visual Studio** that receives a **numeric mark**, determines its **letter grade**, and displays whether the mark is a **pass** or a **fail**.

## Instructions

* Create a new **Console App** project in **Visual Studio**.
* Name the project appropriately.
* Write a program that:

  * asks the user to enter a mark
  * determines the corresponding **character grade**
  * determines whether the mark is a **pass** or a **fail**
  * displays the results on the screen

## Grade Rule

Use the following grading scale:

* `A` for marks from **80 to 100**
* `B` for marks from **70 to 79**
* `C` for marks from **60 to 69**
* `D` for marks from **50 to 59**
* `F` for marks below **50**

A mark of **50 or above** is considered **Pass**.
A mark below **50** is considered **Fail**.

## Requirements

* Use `cout` to display prompts and results.
* Use `cin` to receive input.
* Store the mark in a variable.
* Store the letter grade in a `char` variable.
* The program must clearly display:

  * the entered mark
  * the character grade
  * whether it is pass or fail

## Example Execution

```text
Please enter the mark: 76
Grade: B
Result: Pass
```

```text
Please enter the mark: 43
Grade: F
Result: Fail
```

## Submission Requirements

* Submit the **Visual Studio project**.
* Make sure the program compiles and runs correctly.

## Marking Criteria

* Project created correctly in Visual Studio
* Proper input of the mark
* Correct determination of the character grade
* Correct pass/fail decision
* Clear and correct output
* Good coding style and readability
